# MCP with Playwright - ⛅ Whether Chatbot

An AI Assistant designed to provide real-time weather insights for Israel using MCP.

## Tech Satck
- Python 3.x.x
- MCP SDK
- Playwright

## Get Started

1. Get the repo

    ``` 
    git clone
    cd 
    ```

2. Install Packages
    ```
    uv sync
    ```

3. Execution
    ```
    uv run host.py
    ```
---
